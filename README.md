## Selected Projects

### It's Taste O'Clock — Multilingual Recipe Website

[![Live Website](https://img.shields.io/badge/Live_Website-0F172A?style=flat-square&logo=vercel&logoColor=white)](https://itstasteoclock.vercel.app)

Trilingual recipe website (Turkish, English, French) with Sanity content management, automated DeepL translation, adjustable recipe quantities, and publishing-triggered cache refresh. Built with Next.js and TypeScript, deployed on Vercel, and in use by a food content creator.

[![Live Website](https://img.shields.io/badge/Live_Website-0F172A?style=flat-square&logo=amazonaws&logoColor=white)](https://dogukan-aysan.com/)
